## Purpose and Scope

This page details the structural schema and generation pipeline for `data/top/dataset_final.csv`, the core production dataset for **ciframe**. This comma-separated value file serves as the in-memory database loaded by the Flask backend upon startup, driving song discovery, chord sequence matching, and genre filtering.

* * *

## Column-by-Column Schema Reference

The dataset file `data/top/dataset_final.csv` consists of headerless or standard CSV rows representing individual songs scraped from Cifra Club, enriched with genres, popularity metrics, root keys, and encoded chord progressions [data/top/dataset_final.csv 1-23](https://github.com/joaoarthurbm/ciframe/blob/fb970019/data/top/dataset_final.csv#L1-L23)

| Column Index | Field Name (Logical) | Data Type | Description & Example |
| --- | --- | --- | --- |
| **0** | `ARTIST_SLUG` | String | URL-friendly slug of the artist name (e.g., `14-bis`) [data/top/dataset_final.csv 1](https://github.com/joaoarthurbm/ciframe/blob/fb970019/data/top/dataset_final.csv#L1-L1) |
| **1** | `SONG_SLUG` | String | URL-friendly slug of the song title (e.g., `a-qualquer-tempo`) [data/top/dataset_final.csv 1](https://github.com/joaoarthurbm/ciframe/blob/fb970019/data/top/dataset_final.csv#L1-L1) |

## Chord Sequence Encoding and `SEQ_FAMOSA` Tags

The final column of each record contains the raw chord progression parsed from the source material, preprocessed using chord cleaning routines [data/top/dataset_final.csv 1](https://github.com/joaoarthurbm/ciframe/blob/fb970019/data/top/dataset_final.csv#L1-L1) Chords are flattened into a linear, time-ordered token list separated by semicolons (`;`).

Famous progressions (`SEQ_FAMOSA`) are cross-referenced against pattern mappings defined in auxiliary text configurations. For example, `data/mapeamento_sequencias_famosas.txt` defines canonical progressions such as:

*   `0,Sequência de Bm,Bm - G - D - A`[data/mapeamento_sequencias_famosas.txt 1](https://github.com/joaoarthurbm/ciframe/blob/fb970019/data/mapeamento_sequencias_famosas.txt#L1-L1)
*   `1,Sequência de C,C - G - Am - F`[data/mapeamento_sequencias_famosas.txt 2](https://github.com/joaoarthurbm/ciframe/blob/fb970019/data/mapeamento_sequencias_famosas.txt#L2-L2)
*   `2,Sequência Em,Em - G`[data/mapeamento_sequencias_famosas.txt 3](https://github.com/joaoarthurbm/ciframe/blob/fb970019/data/mapeamento_sequencias_famosas.txt#L3-L3)

When a song's chord sequence contains these specific ordered intervals, the `SEQ_FAMOSA` column is tagged accordingly, allowing the search engine to query songs by famous harmonic structures.

Sources: `data/top/dataset_final.csv:1-23`, `data/mapeamento_sequencias_famosas.txt:1-6`

## Dataset Regeneration and Update Pipeline

Updating or regenerating `dataset_final.csv` involves ingestion scripts that merge raw song data with style maps. The Python script `scripts/add_estilos.py` reads the primary CSV and an external artist-style mapping file (`artista_musica_estilo.txt`) to inject or update the genre (`ESTILO`) column [scripts/add_estilos.py 1-45](https://github.com/joaoarthurbm/ciframe/blob/fb970019/scripts/add_estilos.py#L1-L45)
