## Purpose and Scope

This page details the core data structures and startup indexing mechanisms of the `ciframe` backend application. It covers the `Musica` domain model, CSV column layout definitions, raw chord sequence sanitization via `limpa_cifra`, and the in-memory index construction (`musicas_dict`, `generos`, `acordes`, `genero_musicas`) along with popularity-based sorting performed upon application boot in `main.py`.

Sources: [musica.py 1-25](https://github.com/joaoarthurbm/ciframe/blob/fb970019/musica.py#L1-L25), [main.py 11-98](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L11-L98)

## 1. The `Musica` Domain Class

The `Musica` class encapsulates all domain attributes associated with a single song record parsed from the dataset. It is defined in `musica.py` and instantiated during the startup data ingestion phase.

### Class Attributes & Initialization

The `__init__` constructor receives raw metadata and computes derivative properties such as unique identifiers, distinct chord sets, and external Cifra Club URLs:

*   `self.id_artista`: String identifier for the artist ([musica.py 7](https://github.com/joaoarthurbm/ciframe/blob/fb970019/musica.py#L7-L7)).
*   `self.nome_artista`: Human-readable artist name ([musica.py 8](https://github.com/joaoarthurbm/ciframe/blob/fb970019/musica.py#L8-L8)).
*   `self.id_musica`: String identifier for the song ([musica.py 10](https://github.com/joaoarthurbm/ciframe/blob/fb970019/musica.py#L10-L10)).
*   `self.nome_musica`: Human-readable song title ([musica.py 11](https://github.com/joaoarthurbm/ciframe/blob/fb970019/musica.py#L11-L11)).
*   `self.genero`: Musical genre classification ([musica.py 13](https://github.com/joaoarthurbm/ciframe/blob/fb970019/musica.py#L13-L13)).
*   `self.popularidade`: Integer popularity score ([musica.py 14](https://github.com/joaoarthurbm/ciframe/blob/fb970019/musica.py#L14-L14)).
*   `self.tom`: Musical key (tonality) ([musica.py 15](https://github.com/joaoarthurbm/ciframe/blob/fb970019/musica.py#L15-L15)).
*   `self.cifra`: Cleaned list of chord tokens ([musica.py 16](https://github.com/joaoarthurbm/ciframe/blob/fb970019/musica.py#L16-L16)).
*   `self.acordes`: Unique set of chords derived from the cleaned cifra ([musica.py 17](https://github.com/joaoarthurbm/ciframe/blob/fb970019/musica.py#L17-L17)).
*   `self.seqs_famosas`: List of famous chord sequence tags ([musica.py 18](https://github.com/joaoarthurbm/ciframe/blob/fb970019/musica.py#L18-L18)).
*   `self.id_unico_musica`: Composite primary key formatted as `'{id_artista}_{id_musica}'` ([musica.py 20](https://github.com/joaoarthurbm/ciframe/blob/fb970019/musica.py#L20-L20)).
*   `self.url`: External Cifra Club reference URL ([musica.py 22](https://github.com/joaoarthurbm/ciframe/blob/fb970019/musica.py#L22-L22)).

The `__str__` method returns a comma-separated representation containing `id_unico_musica`, `genero`, and `popularidade` ([musica.py 24-25](https://github.com/joaoarthurbm/ciframe/blob/fb970019/musica.py#L24-L25)).

## 3. Chord Cleaning Algorithm (`limpa_cifra`)

Raw chord data scraped from external sources often contains tablature notation (pipes `|`, spacing, and secondary markers) that must be normalized before indexing or chord-matching operations. The `limpa_cifra(raw_cifra)` function processes raw token lists:

`def limpa_cifra(raw_cifra):    cifra = []    for m in raw_cifra:        if m.strip() != '':            # filtra tablaturas            if '|' in m:                acorde = m.split('|')[0].split()[0]                cifra.append(acorde)            # lida com acordes separados por espaço            else:                tokens = [token for token in m.split()]                cifra += tokens    return cifra`
*   **Tablature Filtering**: If a token contains a pipe character (`|`), it extracts the primary chord token preceding the tab structure ([main.py 16-18](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L16-L18)).
*   **Token Splitting**: Standard space-separated chord tokens are split and appended individually ([main.py 20-22](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L20-L22)).

Sources: [main.py 11-23](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L11-L23)

## 4. Startup Indexing & Popularity Sorting Pipeline

When the Flask application initializes (`main.py`), it reads the entire production dataset into memory and constructs several global index structures designed to accelerate lookups, filtering, and similarity queries.

### Data Ingestion and Index Structures

1.   **`dataset_final.csv` Processing**: Opens `data/top/dataset_final.csv`, skips the header, strips quotes, replaces missing values (`NA`), and parses popularities and chord lists ([main.py 49-64](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L49-L64)).
2.   **`generos` (Set)**: Accumulates all unique musical genres (`[main.py:38]`, [main.py 66](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L66-L66)).
3.   **`musicas_dict` (Dictionary)**: Maps each `id_unico_musica` to its corresponding `Musica` instance (`[main.py:47]`, [main.py 74](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L74-L74)).
4.   **`acordes` (Set)**: Collects all unique chord names present across all processed songs (`[main.py:39]`, [main.py 76-78](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L76-L78)).
5.   **`genero_musicas` (Dictionary)**: Maps each genre string to a list of `Musica` objects belonging to that genre (`[main.py:37]`, [main.py 80-85](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L80-L85)).

### Popularity Ordering

*   **`musicas` (OrderedDict)**: Replaces the raw dictionary with an `OrderedDict` sorted in descending order by `popularidade` ([main.py 88-89](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L88-L89)).
*   **Genre-level Sorting**: Iterates through `genero_musicas` and sorts each genre's song list by popularity in descending order ([main.py 94-96](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L94-L96)).

Sources: [main.py 37-98](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L37-L98)
