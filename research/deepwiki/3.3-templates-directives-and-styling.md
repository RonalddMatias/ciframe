This page covers the frontend template architecture, reusable custom AngularJS directives (`df-hex` and `df-esfinge`), styling systems (`app.css`, `icons.css`), and visual assets of the `ciframe` application. As a leaf page of the wiki, it provides full technical detail on how the AngularJS single-page application renders views, encapsulates UI components, and handles responsive layout styling.

* * *

## 1. View Templates (`static/templates/*`)

The application's UI is divided into modular HTML partials loaded dynamically by the AngularJS router into the main layout shell [static/templates/home.html 1-90](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/home.html#L1-L90)[static/templates/acordes.html 1-96](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/acordes.html#L1-L96)[static/templates/musica.html 1-119](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/musica.html#L1-L119)[static/templates/about.html 1-9](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/about.html#L1-L9)

### Home View (`home.html`)

The landing view [static/templates/home.html 1-90](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/home.html#L1-L90) acts as the primary navigation hub. It embeds the animated Sphinx logo directive (`<df-esfinge>`) [static/templates/home.html 7](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/home.html#L7-L7) an inline SVG logotype (`#DECIFRA-ME`) [static/templates/home.html 10-53](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/home.html#L10-L53) and a vertical panel container [static/templates/home.html 58-88](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/home.html#L58-L88) providing links to the three main feature flows: chord-based search (`#/poracordes`) [static/templates/home.html 61](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/home.html#L61-L61) music-based search (`#/pormusica`) [static/templates/home.html 70](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/home.html#L70-L70) and sequence exploration (`#/porsequencia`) [static/templates/home.html 79](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/home.html#L79-L79)

### Chord Selection View (`acordes.html`)

The chord exploration view [static/templates/acordes.html 1-96](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/acordes.html#L1-L96) uses a split-screen layout (`viewWindow-panel-A` and `viewWindow-panel-D`) [static/templates/acordes.html 3-17](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/acordes.html#L3-L17)

*   **Panel A (Left):** Iterates over chord collections (`Chords.acordes`) and renders interactive `<df-hex>` directives for user interaction [static/templates/acordes.html 6-7](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/acordes.html#L6-L7) When enough chords are selected, a sticky search button triggers navigation to results [static/templates/acordes.html 10-14](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/acordes.html#L10-L14)
*   **Panel D (Right):** Displays matched songs grouped by whether they can be played immediately (`music.diferenca.length == 0`) or require learning new chords (`music.diferenca.length > 0`) [static/templates/acordes.html 43-67](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/acordes.html#L43-L67) Missing chords are rendered as smaller hex badges (`<df-hex small="true">`) [static/templates/acordes.html 85](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/acordes.html#L85-L85)

### Music Selection View (`musica.html`)

The music search view [static/templates/musica.html 1-119](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/musica.html#L1-L119) provides an AngularJS Bootstrap typeahead input (`uib-typeahead`) linked to `Musica.getMusicas($viewValue)`[static/templates/musica.html 13](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/musica.html#L13-L13) Users can select a known song to find similar tracks. Like the chord view, it features a genre filter dropdown [static/templates/musica.html 34-40](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/musica.html#L34-L40) and separates results into fully playable tracks versus those requiring additional chord knowledge [static/templates/musica.html 47-87](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/musica.html#L47-L87)

## 2. Custom Angular Directives (`df-hex` and `df-esfinge`)

The application encapsulates reusable UI widgets into custom AngularJS directives with isolated scopes and dedicated template partials.

### Hexagonal Chord Directive (`df-hex`)

*   **Definition:**`static/assets/js/directives/df-hex.js` defines the `dfHex` directive with an isolated scope binding attribute values [static/assets/js/directives/df-hex.js 1-12](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/assets/js/directives/df-hex.js#L1-L12)
*   **Scope Bindings:**
    *   `acorde`: `@` (string binding for chord name like "C", "Am").
    *   `acordeColor`: `@` (string binding for hex background color).
    *   `acordeChecked`: `=` (two-way boolean binding indicating selection state).
    *   `small`: `=` (boolean flag for rendering compact dimensions).

*   **Template:**`static/templates/directives/df-hex.html` renders an SVG path (`#hex`) styled via `ng-style` and overlays the centered chord name text [static/templates/directives/df-hex.html 1-9](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/directives/df-hex.html#L1-L9)

### Sphinx Logo Directive (`df-esfinge`)

*   **Definition:**`static/assets/js/directives/df-esfinge.js` registers the `dfEsfinge` directive [static/assets/js/directives/df-esfinge.js 1-9](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/assets/js/directives/df-esfinge.js#L1-L9)
*   **Scope Bindings:**
    *   `dfAnimated`: `=` (boolean flag controlling CSS animation classes).

*   **Template:**`static/templates/directives/df-esfinge.html` embeds a complex vector graphic (`svg`) featuring paths, linear groups, and CSS classes (`flyShadow`, `flyUpDown`) bound to `ng-class`[static/templates/directives/df-esfinge.html 1-25](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/directives/df-esfinge.html#L1-L25)

Sources: `static/assets/js/directives/df-hex.js`, `static/templates/directives/df-hex.html`, `static/assets/js/directives/df-esfinge.js`, `static/templates/directives/df-esfinge.html`

## 3. Styling, Panels, and Animations (`app.css`, `icons.css`)

### Layout Panels and View Windows

The CSS layer provides a responsive split-panel system using custom classes:

*   `.container-fluid` and `.row`: Bootstrap grid foundation.
*   `.viewWindow-panel`: Full-height flex/absolute column containers (`viewWindow-panel-A` through `F`) [static/templates/musica.html 3-27](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/musica.html#L3-L27)[static/templates/acordes.html 3-17](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/acordes.html#L3-L17)[static/templates/home.html 3-58](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/home.html#L3-L58)
*   `.music-card`: Card component styling for song items with hover elevations and status indicators [static/templates/musica.html 49-67](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/templates/musica.html#L49-L67)

### Icon Fonts (`icomoon`)

The custom icon font `icomoon` is loaded via `static/assets/css/icons.css`[static/assets/css/icons.css 1-10](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/assets/css/icons.css#L1-L10) supporting WOFF, TTF, EOT, and SVG formats [static/assets/css/fonts/icomoon.ttf](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/assets/css/fonts/icomoon.ttf)[static/assets/css/fonts/icomoon.woff](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/assets/css/fonts/icomoon.woff)

*   **Glyph Mappings:**
    *   `.icon-key:before`: `\e900`[static/assets/css/icons.css 27-29](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/assets/css/icons.css#L27-L29)
    *   `.icon-lock:before`: `\e901`[static/assets/css/icons.css 30-32](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/assets/css/icons.css#L30-L32)
    *   `.icon-lock-open:before`: `\e902`[static/assets/css/icons.css 33-35](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/assets/css/icons.css#L33-L35)
