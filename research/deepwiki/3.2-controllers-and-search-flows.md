This page details the implementation and data flow of the AngularJS controllers within the `deciframeApp` frontend module [static/assets/js/controllers/acordes.js 1](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/assets/js/controllers/acordes.js#L1-L1) Controllers act as the bridge between user interactions in the SPA templates and the backend REST API. They manage query construction, asynchronous `$http` lifecycles, progress indication via `ngProgress`, conversational UI feedback through `esfigeSpeech` states, and result rendering.

* * *

## 1. AcordesController

`AcordesController` manages the chord selection interface, grouping chords by musical keys and triggering live similarity queries when chords are toggled.

### Chord Matrix and Palette Initialization

### Chord Selection and Search Flow

*   `vm.addAcorde(acorde)`: Adds an unselected chord to `vm.meusAcordes` or removes it if already present. Upon modification, it immediately invokes `vm.pesquisarPorAcordes()` [static/assets/js/controllers/acordes.js:63-71].
*   `createChordsString(chords)`: Utility function that serializes an array of chord objects into a comma-separated string (e.g., `C,Am,F,G`) [static/assets/js/controllers/acordes.js:76-82].
*   `vm.pesquisarPorAcordes()`: Constructs the query string, initiates `ngProgress`, updates `vm.esfigeSpeech`, and performs an asynchronous `$http.get` request against the `similares` endpoint [static/assets/js/controllers/acordes.js:84-115].

## 2. MusicaController

`MusicaController` handles song-based similarity searches and autocomplete song lookups.

### Key Functions

*   `vm.getMusicas(val)`: Interfaces with the `/search` endpoint to provide autocomplete suggestions based on a query string `val` [static/assets/js/controllers/musica.js:14-20].
*   `vm.pesquisarPorMusica(musica)`: Takes a selected song object, extracts its `id_unico_musica`, and queries the backend for structurally similar tracks [static/assets/js/controllers/musica.js:43-70].

_Sources: [static/assets/js/controllers/musica.js 14-70](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/assets/js/controllers/musica.js#L14-L70)_

## 3. SequenciaController

`SequenciaController` manages predefined famous chord progressions (`sequenciasFamosas`) as well as custom sequence inputs.

### Famous Progressions and Search

The controller initializes four standard chord sequences (e.g., `Bm-G-D-A`, `C-G-Am-F`) [static/assets/js/controllers/sequencia.js:2-37].

*   `vm.pesquisarPorSequencia(sequencia)`: Serializes the selected sequence's chords using `createChordsString` and executes an HTTP GET request to `/similares?sequencia=...` [static/assets/js/controllers/sequencia.js:63-90].
*   Optional genre filtering is supported via `vm.meuGenero` [static/assets/js/controllers/sequencia.js:74-76].

_Sources: [static/assets/js/controllers/sequencia.js 63-90](https://github.com/joaoarthurbm/ciframe/blob/fb970019/static/assets/js/controllers/sequencia.js#L63-L90)_

## 5. Asynchronous Lifecycle, ngProgress, and esfigeSpeech

All search controllers (`AcordesController`, `MusicaController`, `SequenciaController`) share a standardized asynchronous execution lifecycle coordinated by `ngProgressFactory` [static/assets/js/controllers/acordes.js:1] [static/assets/js/controllers/musica.js:1] [static/assets/js/controllers/sequencia.js:1]:

1.   **Initialization (`.start()`)**: Triggered immediately when a search action begins. The progress bar starts animating across the top of the viewport [static/assets/js/ngprogress.js:38-55].
2.   **State Transition (`esfigeSpeech`)**: The conversational assistant prompt (`vm.esfigeSpeech`) updates to indicate searching status (e.g., `"Procurando músicas..."`) [static/assets/js/controllers/acordes.js:87].
3.   **Data Resolution (`.success()` / `.error()`)**: 
    *   On success, `ngProgress.complete()` finishes the progress animation [static/assets/js/ngprogress.js:137-149], `vm.esfigeSpeech` updates to `"Encontrei essas músicas"`, and `vm.musics` is populated with the resulting array [static/assets/js/controllers/acordes.js:98-102].
    *   On error, `vm.esfigeSpeech` switches to `"Ops! Algo errado."` and search count visibility is reset [static/assets/js/controllers/acordes.js:104-108].
