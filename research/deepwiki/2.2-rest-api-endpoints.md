## Purpose and Scope

This page documents the REST API endpoints exposed by the Flask backend application in `main.py`. It details request parameters, optional filtering logic, pagination limits (`TAM_PAGINA`), and JSON response shapes. The endpoints serve metadata, full song collections, targeted searches, and chord-based or sequence-based similarity recommendations to the AngularJS frontend.

Sources: [main.py 1-214](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L1-L214)[requirements.txt 1-5](https://github.com/joaoarthurbm/ciframe/blob/fb970019/requirements.txt#L1-L5)

## Core Routing (`/` and `/<path>`)

The base routes handle the delivery of the single-page application shell and static assets.

*   `@app.route('/')`: Maps to `index()`[main.py 101-103](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L101-L103) which invokes `app.send_static_file('index.html')` to load the AngularJS client application container.
*   `@app.route('/<path:path>')`: Maps to `static_proxy(path)`[main.py 109-112](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L109-L112) which dynamically serves static resources (JavaScript controllers, CSS stylesheets, HTML templates) from the static folder with automatic MIME-type detection.

Sources: [main.py 101-112](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L101-L112)

* * *

These endpoints provide access to global datasets parsed during application startup: unique genres, unique chords, and the complete collection of songs ordered by popularity.

*   `/musicas`: Handled by `get_musicas()`[main.py 154-156](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L154-L156) Returns a JSON-serialized list of all song dictionaries (`[v.__dict__ for v in musicas.values()]`) sorted descending by popularity.
*   `/generos`: Handled by `get_generos()`[main.py 158-160](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L158-L160) Returns a JSON array of unique genre strings collected in `generos`.
*   `/acordes`: Handled by `get_acordes()`[main.py 162-164](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L162-L164) Returns a JSON array of unique chord tokens extracted across all loaded cifra data.

Sources: [main.py 154-164](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L154-L164)

## Item Retrieval and Search Endpoints

### Single Song Retrieval (`/musica/<m_id>/`)

*   **Route:**`@app.route('/musica/<m_id>/')`[main.py 166-168](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L166-L168)
*   **Function:**`get_musica(m_id)`[main.py 167-168](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L167-L168)
*   **Parameters:**`m_id` (string matching `id_unico_musica`, formatted as `id_artista_id_musica`[musica.py 20](https://github.com/joaoarthurbm/ciframe/blob/fb970019/musica.py#L20-L20)).
*   **Response Shape:** JSON dictionary representing the `Musica` object's `__dict__`, containing artist ID, song ID, names, genre, popularity, key, cleaned chord list (`cifra`), unique chords (`acordes`), famous sequences (`seqs_famosas`), and external URL.

### Search Collection (`/search`)

*   **Route:**`@app.route('/search')`[main.py 114-115](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L114-L115)
*   **Function:**`busca()`[main.py 115-142](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L115-L142)
*   **Parameters:**
    *   `key`: String containing search terms (matched against artist name or song title).
    *   `generos`: Optional comma-separated list of genre filters (defaults to all `generos`) [main.py 116-123](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L116-L123)
    *   `pagina`: Page number for pagination (defaults to `'1'`) [main.py 117](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L117-L117)

*   **Implementation & Data Flow:**
    1.   Extracts `generos_tag` and lowercases/normalizes `key` using `remover_combinantes()`[main.py 116-147](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L116-L147)
    2.   Filters songs using `apply_filtro()`[main.py 125](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L125-L125)
    3.   Tokenizes artist and song names, checking if all search tokens match (`all(key in text_list for key in keys)`) [main.py 129-131](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L129-L131)
    4.   Constructs summary match dictionaries (`id_unico_musica`, `id_artista`, `id_musica`, `nome_artista`, `nome_musica`, `genero`, `url`) [main.py 132-140](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L132-L140)
    5.   Applies pagination via `get_pagina(out, pagina_tag)` restricted by pagination boundary `TAM_PAGINA`[main.py 35-142](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L35-L142)

Sources: [main.py 35-168](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L35-L168)[musica.py 1-23](https://github.com/joaoarthurbm/ciframe/blob/fb970019/musica.py#L1-L23)

## Similarity and Sequence Endpoints (`/similares`)

The `/similares` endpoint handles recommendation logic based on raw chord arrays, source song IDs, or predefined famous chord progressions.

*   **Route:**`@app.route('/similares')`[main.py 170-171](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L170-L171)

*   **Function:**`get_similares()`[main.py 171-201](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L171-L201)

*   **Parameters:**

    *   `acordes`: Optional comma-separated list of chord tokens.
    *   `id_unico_musica`: Optional source song ID to inherit chords from [main.py 174](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L174-L174)
    *   `sequencia`: Optional famous sequence identifier string (e.g., `'BmGDA'`, `'CGAmF'`) [main.py 40-175](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L40-L175)
    *   `generos`: Optional comma-separated genre filter list [main.py 179-183](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L179-L183)
    *   `pagina`: Page number (defaults to `'1'`) [main.py 176](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L176-L176)

*   **Branching Logic:**

    *   If `acordes_tag` is present, splits into a chord list [main.py 184-186](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L184-L186)
    *   If `id_musica_tag` is present, retrieves the source `Musica` object from `musicas` and extracts its `.acordes`[main.py 187-189](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L187-L189)
    *   If `sequencia_tag` is present, cleans punctuation, verifies presence in `sequencias`, and queries matching songs via `get_similares_por_sequencia()`[main.py 190-220](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L190-L220)
    *   Otherwise, invokes general similarity matching (`get_similares(acordes, generos_key, id_musica_tag)`) [main.py 199](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L199-L199)

*   **Pagination:** All results are passed through `get_pagina(similares, pagina_tag)` [main.py:196, 201] using the page size constant `TAM_PAGINA = 100`[main.py 35](https://github.com/joaoarthurbm/ciframe/blob/fb970019/main.py#L35-L35)
